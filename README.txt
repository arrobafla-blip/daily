DAILY. — PACOTE DO PROTÓTIPO

Arquivos:
- index.html: página principal
- style.css: estilos, cores, fontes e layout responsivo
- script.js: interações demonstrativas
- README.txt: estas instruções

COMO PUBLICAR:
1. Baixe e extraia este ZIP no seu computador.
2. No repositório GitHub do Daily, clique em Add file > Upload files.
3. Envie os 3 arquivos: index.html, style.css e script.js, para a raiz do repositório. Pode enviar também este README.txt.
4. Clique em Commit changes.
5. Settings > Pages deve continuar configurado para Deploy from a branch, main, /(root).
6. Aguarde o GitHub Pages atualizar e abra o endereço publicado.

IDENTIDADE VISUAL:
Este protótipo usa as famílias e os valores encontrados no CSS público do Call Creative Studio:
Space Grotesk e DM Mono; rosa #f4a4c7, rosa intenso #ff4f9a, papel #f8f5ef, preto #171515 e cinza #6e6669.

IMPORTANTE:
Este é um protótipo visual. Tarefas, água e hábitos funcionam apenas temporariamente no navegador; não há login, banco de dados nem salvamento permanente. Os outros módulos aparecem como navegação de demonstração. As fontes são carregadas do Google Fonts e precisam de conexão com a internet.
